
# UNIONIUM DEVELOPMENT SCRIPTS

This directory contains scripts for maintaining
the Unionium Chromium fork.

## Planned Scripts

- check_environment.py
- verify_revision.py
- validate_patches.py
- prepare_build.py
- collect_build_info.py

## Requirements
- Python 3
- Git
- Linux x86-64 for Chromium builds

## Security
- Never store credentials in scripts.
- Never expose signing keys.
- Validate all external inputs.
- Avoid destructive operations by default.

Documentation only.
