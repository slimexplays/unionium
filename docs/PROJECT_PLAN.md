
# UNIONIUM

Your Browser. Your Internet.

## Project Overview

Unionium is an Android browser based on a
custom fork of the Chromium open-source project.

## Project Configuration

- Name: Unionium
- Package ID: com.slimex.unionium (target)
- Platform: Android
- Engine: Chromium Android source
- Architecture: ARM64
- Interface: Premium Black + Purple
- Design: Futuristic
- Repository: Private GitHub

## Core Features

- Custom browser homepage
- Multi-tab browsing
- Private browsing
- Bookmarks and history
- Download manager
- Desktop mode
- Privacy controls
- Security settings
- Developer tools
- Custom browser branding

## Development Architecture

- GitHub: Source repository
- Android phone: Project control panel
- AI assistance: Development support
- Cloud build: Chromium compilation
- APK: Android distribution

## Build Strategy

- Keep Chromium source separate.
- Pin a tested Chromium revision.
- Maintain custom patches separately.
- Verify build environment before compilation.
- Never commit signing keys or API secrets.
