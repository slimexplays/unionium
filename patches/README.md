
# UNIONIUM PATCH MANAGEMENT

All custom Chromium modifications must be
maintained separately from upstream source.

## Patch Categories

### Android
Android-specific application modifications.

### Branding
Unionium logos, icons, application identity
and visual assets.

### Browser UI
Toolbar, homepage and browser interface.

## Patch Rules
- One logical change per patch.
- Use descriptive filenames.
- Record the Chromium commit SHA.
- Include patch descriptions.
- Test patches before integration.
- Never overwrite upstream source blindly.
